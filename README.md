# Scraping and Data Cleaning Task

This project has two parts:

1. **Scraping Books**: collecting book data (category, name, price, stock) from https://books.toscrape.com/
2. **Data Cleaning**: cleaning 5 CSV files (customers, products, orders, new daily batch, previous days summary)

## Folders
- `Data Before cleaning`: the original files
- `Data After cleaning`: the cleaned files and the cleaning code (`cleaning.ipynb`)
- `Scraping Books`: the scraping code (`scraping.ipynb`) and its output (`books.csv`)

## Tools
Python, pandas, requests, BeautifulSoup
